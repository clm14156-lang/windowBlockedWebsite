# 专注时光 · 产品官网

使用原生 HTML、CSS 和 JavaScript ES Modules，无第三方运行依赖。四个页面由同一组组件生成完整 HTML，可直接作为静态网站部署。

## 本地运行

```sh
node scripts/server.mjs --port 5175
```

打开 `http://127.0.0.1:5175/features/`。修改服务端路由或组件后需要重启服务；样式与浏览器脚本修改后刷新即可。Windows 启动脚本也可继续使用。

## 页面

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 功能介绍 | `/features/` | 首屏交互计时、设置步骤、访问拦截、悬浮演示、目标任务、统计轮播、功能总结、个性化主题与角色及收尾 |
| 下载软件 | `/download/` | Windows 产品入口、下载开放状态、在线体验和安装步骤 |
| 高级会员 | `/membership/` | 免费版 / 专业版方案对比与权益预览 |
| 帮助中心 | `/help/` | 8 项原生可折叠问答 |

根路径显示功能介绍页。访问拦截和目标任务仅为功能介绍页内的区块，没有独立导航或路由。未知页面返回带回首页入口的 404，静态构建也提供 `404.html`。

## 视觉与交互

- 页面底色 `#FBFBFB`，统一 1160px 内容宽度、浅色表面、橙色操作按钮、字号、留白与边框。
- `styles.css` 管理官网设计系统；`styles/product.css` 隔离现有软件界面的几何与样式。网站不再混用夜景整屏背景、装饰连线和海报式拼图。
- 三步设置以「从设置到专注，只需三步。」为标题，左侧采用数字连线、圆形图标和浅橙色当前步骤，右侧完整展示较大的正面软件窗口。复用 `assets/product/lunbo_001～003.png`，仅去除透明画布边缘；添加网站状态使用明亮的列表底图和原截图中的完整弹窗，避开深灰遮罩。支持步骤、左右箭头、方向键 / Home / End 与横向滑动联动，400ms 轻柔过渡；默认手动浏览。移动端使用横排步骤，当前步骤说明保留在轮播下方。
- 设置与目标展示复用同一面板选择控制器，每次仅一个面板可交互。目标与任务以 `00a.png` 主界面、`00b.png` 悬浮任务窗、`00c.png` 快速创建弹窗组成连续展示，保留原比例、步骤点击及方向键切换；选择步骤时强调对应窗口，另外两张保留为视觉预览。窄屏使用纵向布局，所有步骤说明仍可见。
- 悬浮演示保留原生滚动驱动，并缩短滚动行程。
- 网站拦截采用固定的双浏览器前后对比，左侧保留哔哩哔哩浏览器素材，右侧完整展示 `blocked01.png` 并放大为视觉主体。中间为不可交互的橙色「自动拦截」标签与方向箭头，不再提供访问状态切换；底部保留三项说明。窄屏上下排列，箭头相应朝下，两张图片均保持原始比例。
- 统计采用居中主窗口与左右前后页横向预览，主图保持原尺寸与 100% 不透明度，两侧统一为 20%，卡片正面朝向且互不重叠。使用 `tongji01～03.png` 原比例截图和无损 WebP，轨道 440ms 横向移动，首尾副本实现连续循环，快速操作会合并为最新选择。保留原有标题、三项功能说明、箭头、功能入口、圆点与可选 4.5 秒自动播放；默认暂停，悬停、焦点、页面隐藏、离屏及减少动态效果时暂停。切换前等待图片解码，失败保留当前界面并提示，标题与指示器同步变化；窄屏保留中间窗口大小并裁切两侧预览，避免页面横向溢出。
- 生活价值区块保留「把生活的节奏还给自己」及两行深蓝 / 橙色标题，改为三张等宽等高的白色图文卡片。使用项目实际文件 `jaizhi01.png`、`jiazhi02.png`、`jiazhi03.png`，原比例完整展示插画；每张包含暖橙色线条图标、价值说明和米色区域中的三个勾选要点。下方保留「改变，不需要从完美的一天开始。」与补充说明，窄屏纵向排列。导航结构、链接、菜单、体验入口和既有区块高亮逻辑保持原样。
- 首屏支持白天 / 夜晚：`focus03` + `juese/white_boy01`、`dark_background02` + `juese/dark_boy01` 分层显示。默认白天，等待目标图片解码后淡入切换；计时与 UI 位置保持一致。移除首屏悬浮计时与查看任务入口，底部保留较轻的居中任务结束 / 开始操作。下载页继续使用 `focus02.png`，独立的悬浮演示保持不变。
- 首屏网页背景使用项目实际文件 `background03.png`（提供无损 WebP），底部柔和过渡到后续区块。导航在页首透明，有滚动时显示轻白底与模糊效果，回到顶部恢复透明。
- 首屏默认展示 `/assets/product/image1.png` 的原比例软件首页，以轻微俯视透视呈现。原生滚动驱动展示平面逐渐立起，软件首页淡出、原有真实倒计时淡入；最终为无角度正视界面。固定展示区和短距离 sticky 行程保留首屏排版，向上滚动可逆，不重置计时和主题。倒计时及昼夜控件仅在可见时可交互，减少动态效果偏好下取消透视；首页图加载失败则显示原倒计时。
- 个性化主题与角色位于收尾之前，是功能介绍的倒数第二屏。与首屏复用 `initHeroTheme` 状态与加载控制器、`themeScenes` 场景组件和 360ms 淡入样式。7 个角色的昼夜对应关系在 `src/focus-characters.js` 显式维护，包括 `white_littlerabbit` / `dark_rabbit` 特例和夜间考拉的 1254px 尺寸；切换主题保留角色，缺失或加载失败时明确提示并保留上一次有效选择。
- 收尾屏使用 `last_page.png` 自带的透明天空与风景角色，保留图片比例并居中裁切，文字和按钮为独立 HTML。单个「下载 Windows 版」按钮沿用现有下载入口；未配置安装包地址时前往下载页，配置后使用正式 HTTPS 地址。宽屏和窄屏分别保留足够场景高度，避免文字、按钮与角色重叠。
- 插画提供 WebP 与原 PNG 回退，独立角色的 WebP 保留无损透明通道。首屏预加载白天背景，其余区块插画及软件截图按需懒加载。
- 在线体验支持倒计时、任务勾选、统计周期及日期切换。状态仅保存在当前页面内存，不会修改系统、创建账号或订单。

## 发布配置

按当前要求，下载与会员保留明确的占位状态。网站不会生成虚假安装包，也不会执行真实付款。

正式接入时修改 `src/site-config.js`：`origin` 为 HTTPS 正式域名，`downloadUrl` 为 HTTPS 官方安装包地址，`checkoutUrl` 为 HTTPS 购买页面，`version` 为正式版本。价格与权益在 `src/data.js` 中维护；启用真实购买前同步更新方案、帮助与服务说明。

填写正式域名后，构建会生成对应的 canonical、分享链接、图片地址与 sitemap。域名为空时不生成虚假 canonical 或 sitemap。每页已有独立标题、描述、Open Graph 元信息；404 使用 noindex。

```sh
node scripts/check.mjs
node scripts/test-product-tabs.mjs
node scripts/test-setup-carousel.mjs
node scripts/test-floating.mjs
node scripts/test-hero-timer.mjs
node scripts/test-hero-theme.mjs
node scripts/test-hero-presentation.mjs
node scripts/test-personalization.mjs
node scripts/test-statistics-carousel.mjs
node scripts/test-routes.mjs
node scripts/build.mjs
```

构建结果为 `dist/`，部署该目录到支持目录索引的 HTTP 静态服务器。无需 SPA 回退；将 404 错误页映射至 `404.html`。每次构建会校验并重新生成整个 `dist/`，防止残留旧页面和脚本；不要手工存放文件在此目录。构建同时生成 robots.txt。

`src/site-shell.js` 负责共享导航、页脚及独立页面；`src/components.js` 组装产品演示；`src/product-tabs.js` 负责可访问的面板切换；`src/hero-timer.js` 与 `src/floating-demo.js` 维护计时和悬浮状态。素材来源与产品事实见 `docs/`。
