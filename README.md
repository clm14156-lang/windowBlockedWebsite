# 专注时光 · 产品官网

使用原生 HTML、CSS 和 JavaScript ES Modules，无第三方运行依赖。四个页面由同一组组件生成完整 HTML，可直接作为静态网站部署。

## 本地运行

```sh
node scripts/server.mjs --port 5175
```

打开 `http://127.0.0.1:5175/features/`。修改服务端路由或组件后需要重启服务；样式与浏览器脚本修改后刷新即可。Windows 启动脚本也可继续使用。

## 页面

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 功能介绍 | `/features/` | 首屏交互计时、设置步骤、访问拦截、悬浮演示、目标任务、统计轮播、功能总结、个性化主题与角色及收尾 |
| 下载软件 | `/download/` | 直接下载入口、白天软件预览及三项核心功能 |
| 高级会员 | `/membership/` | 免费版 / 专业版方案对比与权益预览 |
| 帮助中心 | `/help/` | 原始插画、四类帮助入口与 8 项原生可折叠问答 |

根路径显示功能介绍页。访问拦截和目标任务仅为功能介绍页内的区块，没有独立导航或路由。未知页面返回带回首页入口的 404，静态构建也提供 `404.html`。

## 视觉与交互

- 所有主区块共用 `styles/screens.css` 的自然内容高度和有上下限的 `rem` / `clamp()` 间距，不再强制占满视口或垂直居中。固定导航高度只计入每条路由首个区块的上边距，其余区块保持统一间距，锚点滚动避开导航。
- 软件演示保持各组件的宽度上限和图片比例。所有区块按内容自然排列，不按视口高度强制撑高；首屏动画直接利用软件展示随页面向上移动的行程，不吸附、不增加滚动占位。三种专注形态区块通过三张卡片同时展示专注页面、悬浮页面和折叠页面。
- 页面底色 `#FBFBFB`，统一 1160px 内容宽度、浅色表面、橙色操作按钮、字号、留白与边框。
- 所有页面的营销文字共用 `styles/typography.css`：沿用系统字体栈，以 `rem` 定义字号，桌面 / 平板 / 手机共用同一套层级。页面大标题为 56 / 44 / 36px，功能区块标题为 44 / 36 / 30px，正文为 16 / 16 / 15px；统一字重、行高、字距、文字色和标题间距。导航、页脚、按钮与官网弹窗也使用共享规则，页面专用样式不再覆盖字体。价格、演示倒计时及软件预览内部文字保留专用规格。完整标准与验收范围见 `docs/typography-audit-and-plan.md`。
- 所有路由复用同一个导航组件与 `styles.css` 的导航样式，下载页、会员页和价值区块不再单独覆盖导航。切页只更新当前页高亮；导航在页首透明，滚动后使用统一的轻白背景，尺寸、字号、间距、体验按钮和移动菜单保持一致。
- 会员页使用隔离的 `styles/membership.css`：柔和蓝橙背景、居中标题、等宽方案卡片和四列产品说明；窄屏卡片纵向排列，内容自然撑高。价格、计费说明、功能开关与体验 / 升级按钮行为不变，仍保留现有方案预览提示；不添加未经确认的永久授权、多设备、同步或客服承诺。
- 下载页使用隔离的 `styles/download.css`：左侧大标题与直接 Windows 下载入口，右侧放大原有白天预览，底部只保留屏蔽、计时、任务与统计三项说明。移除下载信息卡、三步安装说明及下载区的在线体验入口，保留导航免费体验。预览组件的背景、角色、计时与任务入口保持原样；项目暂未提供参考图带左侧栏的完整白天截图。下载 URL 的 HTTPS 校验和未配置时的禁用状态不变，不增加未确认的系统版本或安装承诺。
- 帮助页使用原始 `helpbackground.png` 插画与隔离的 `styles/help.css`，仅调整内容及帮助页页脚，不修改导航。四类卡片在桌面横排、窄屏换行；下载分类保留原下载页跳转，其余分类通过原生锚点定位并展开现有 FAQ。`src/help-center.js` 只负责分类和直接链接的答案展开，8 条原文保持不变，默认全部折叠，普通展开 / 收起由原生 `details` 完成，不拦截页面滚动。

## 发布配置

按当前要求，下载与会员保留明确的占位状态。网站不会生成虚假安装包，也不会执行真实付款。

正式接入时修改 `src/site-config.js`：`origin` 为 HTTPS 正式域名，`downloadUrl` 为 HTTPS 官方安装包地址，`checkoutUrl` 为 HTTPS 购买页面，`version` 为正式版本。价格与权益在 `src/data.js` 中维护；启用真实购买前同步更新方案、帮助与服务说明。

填写正式域名后，构建会生成对应的 canonical、分享链接、图片地址与 sitemap。域名为空时不生成虚假 canonical 或 sitemap。每页已有独立标题、描述、Open Graph 元信息；404 使用 noindex。

```sh
node scripts/check.mjs
node scripts/test-help-center.mjs
node scripts/test-download.mjs
node scripts/test-membership.mjs
node scripts/test-screen-layout.mjs
node scripts/test-product-tabs.mjs
node scripts/test-setup-carousel.mjs
node scripts/test-floating.mjs
node scripts/test-hero-timer.mjs
node scripts/test-hero-theme.mjs
node scripts/test-hero-presentation.mjs
node scripts/test-personalization.mjs
node scripts/test-statistics-carousel.mjs
node scripts/test-routes.mjs
node scripts/build.mjs
```

构建结果为 `dist/`，部署该目录到支持目录索引的 HTTP 静态服务器。无需 SPA 回退；将 404 错误页映射至 `404.html`。每次构建会校验并重新生成整个 `dist/`，防止残留旧页面和脚本；不要手工存放文件在此目录。构建同时生成 robots.txt。

`src/site-shell.js` 负责共享导航、页脚及独立页面；`src/components.js` 组装产品演示；`src/product-tabs.js` 负责可访问的面板切换；`src/hero-timer.js` 维护下载预览的计时状态。素材来源与产品事实见 `docs/`。
