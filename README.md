# 专注 · 产品官网

使用 HTML、CSS 和原生 JavaScript ES Modules，页面底色统一为 `#FBFBFB`，保留原有导航栏、字体、软件展示与动效，无第三方运行依赖。

## 运行

Windows 双击 `启动网站.cmd` 或 `start-preview.cmd`，自动启动后台服务并打开 http://127.0.0.1:5174/ 。日志位于 `.preview/server.log`。优先使用本机 Node.js，未安装时使用当前电脑已有的 Codex Node.js 运行时。

也可以使用 Node.js 18 或以上运行：

```sh
node scripts/server.mjs
```

默认地址 http://127.0.0.1:5173/ ，可通过 `--port 端口号` 指定端口。修改服务端路由或组件后，需要重启此命令；仅修改 CSS 和浏览器脚本时刷新页面即可。

## 页面结构

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 功能介绍 | `/features/` | 原首屏、三步设置、访问拦截、悬浮运行、目标与任务、专注统计、真实改变及夜景下载收尾 |
| 下载软件 | `/download/` | 下载页占位图，保留独立路由与导航 |
| 高级会员 | `/membership/` | 完整的免费版 / 专业版定价、权益和方案选择 |
| 帮助中心 | `/help/` | 完整的 8 项常见问题与回答 |

根地址 `/` 显示功能介绍页。导航、品牌链接和下载入口使用普通页面链接；每页拥有独立 HTML、标题、描述和当前导航状态。原生浏览器历史支持前进、后退及新标签页打开。页面加载与历史恢复均回到顶部，页面内的功能提示和下载详情仍可使用锚点。

导航内容最大宽度为 1160px，在 1920px 页面中左右各留白 380px。页面、纯色功能区块及页脚使用 `#FBFBFB` 底色，导航使用同色的半透明背景，并配套深色正文。首屏不使用风景背景，仅以低透明度的浅蓝、浅暖色渐变轻微点缀，并预加载实际展示的软件窗口图片。结尾、目标与任务的风景图片及软件界面的深色展示保留独立配色。原「为专注，留一点空间」卡片已移除；结尾的下载按钮进入独立下载占位页。

## 检查与构建

```sh
node scripts/check.mjs
node scripts/test-setting.mjs
node scripts/test-floating.mjs
node scripts/test-hero-timer.mjs
node scripts/test-routes.mjs
node scripts/build.mjs
```

构建结果在 `dist/`。四个路由分别输出各自的 `index.html`，可以部署在支持目录索引的静态服务器根目录，不需要 SPA 回退规则。构建会清理原访问拦截、目标与任务的旧独立页面导出；这两个功能仅保留在功能介绍页中，不再注册独立路由。不要直接用 `file://` 打开页面，ES Modules 需要 HTTP 服务。

结构检查覆盖内容归属、文案完整性、导航、锚点、ARIA、素材和页面文档；设置流程测试覆盖三张图片映射、均分滚动区间、切换边界和向上还原；悬浮测试覆盖 8 种尺寸、滚动进度、连续过渡、向上还原、右上角定位和减少动态效果；HTTP 测试覆盖直接访问、路由别名、HEAD、静态资源和 404。

## 交互与接入

首屏专注窗口使用项目原图 `assets/focus02.png`，以 3:2 比例完整展示白天风景及图中已有的角色；太阳、问候语、计时、目标和底部操作为独立 HTML/SVG/CSS。浅色窗口边框、白色悬浮计时及其样式仅应用于首屏。主时钟、右侧悬浮时钟与环形进度由同一份状态驱动，保留结束、继续、归零后重新开始及任务演示入口。

目标与任务展示保留在功能介绍页内，位于悬浮运行之后、专注统计之前。桌面端还原三栏步骤、目标创建窗口、目标任务列表、日间专注窗口和前置快速任务面板；手机和平板使用纵向排列。软件界面为独立 HTML/CSS 产品预览，页面内未接入真实目标或任务数据。背景和日间风景的素材及生成提示词见 `docs/goals-artwork.md`。

访问拦截展示保留在功能介绍页内，紧接三步设置中的「开始专注」。两个浏览器、步骤标签、弧形箭头、网站信息及状态均为独立 HTML/SVG/CSS；提示页夜景复用 `assets/blocked_background.png`。桌面端使用前后叠放，手机端改为上下两步展示。倒计时仅在页面可见且进入视口时递减；这是官网内的使用效果演示，不会访问或拦截真实网站。

「让专注，带来真实的改变」为功能介绍页倒数第二个区块，紧接专注统计、位于「愿你拥有，不被打扰的时光」之前。复用官网字体及盾牌、目标、统计图标，以独立 HTML/CSS 实现统一浅色底、两行标题、说明及三项功能总结；没有新增导航或路由。

设置流程使用原生 JavaScript 组件与 CSS sticky：固定展示区域停留在导航栏下方，将滚动行程均分为添加网站、开启屏蔽、开始专注三个步骤。右侧固定容器依次展示 `setting_a1.png`、`setting_a2.png`、`setting_a3.png`，以 280ms 淡入淡出及 10px 纵向位移切换；左侧只展开当前步骤说明。第三步展示完毕后自然离开，上滚恢复对应步骤。没有自动播放或点击切换，未拦截滚轮与触屏事件。图片路径、尺寸和文案统一在 `src/setting-steps.js` 配置。

功能页保留倒计时、任务清单、统计周期及日期切换。悬浮运行区采用上方居中文案、下方全内容宽度桌面的结构。桌面演示在滚动阶段短暂停留，窗口随向下滚动连续缩小、淡出为桌面右上角的计时条；向上滚动沿相同轨迹恢复。折叠仅由滚动进度决定，没有自动播放、点击切换、拖动吸附或重播按钮。系统选择减少动态效果时，以静态状态切换代替位移。软件窗口底部操作栏及右上角装饰仅作静态展示，悬浮区允许正常触屏滚动。其他页面仅初始化其实际存在的组件，导航状态由当前路由决定。

所有交互均为前端演示，演示状态保存在当前文档内存中，刷新重置。下载页暂为占位图，后续接入安装包时替换；会员方案选择不会创建订单或产生扣费。正式接入时更新下载页入口、`src/app.js` 的 `showUpgrade()`、价格权益和隐私政策。

## 文件结构

- `src/routes.js`：四个页面的路径、标题和描述。
- `src/goals-preview.js`：功能介绍页内的目标与任务三栏展示。
- `src/blocking-preview.js`：功能介绍页内的访问拦截双浏览器展示。
- `src/impact-section.js`：功能介绍页倒数第二个真实改变区块。
- `src/components.js`：共享导航、页脚、弹窗及各页面内容。
- `src/app.js`：页面内交互、状态和滚动恢复。
- `src/hero-timer.js`：首屏主时钟与右侧悬浮时钟的同步、进度及专注状态。
- `src/floating-demo.js`：独立的悬浮窗演示。
- `src/setting-demo.js`：三步设置的滚动进度与当前步骤控制。
- `src/setting-steps.js`：设置流程文案、截图及替代文本配置。
- `src/data.js`：原有价格、权益及 FAQ 文案。
- `src/icons.js`：本地 SVG 图标与品牌。
- `styles.css`：视觉规范与响应式样式。
- `scripts/document.mjs`：生成每个路由的完整 HTML。
- `scripts/server.mjs` / `build.mjs`：本地预览与静态页面构建。
- `assets/`、`sc/` 及原始参考 PNG：软件截图、背景及原始素材。
