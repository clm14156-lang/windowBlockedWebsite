# 专注 · 产品官网

使用 HTML、CSS 和原生 JavaScript ES Modules，保留深蓝配色、原有导航栏、字体、软件展示与动效，无第三方运行依赖。

## 运行

Windows 双击 `启动网站.cmd` 或 `start-preview.cmd`，自动启动后台服务并打开 http://127.0.0.1:5174/ 。日志位于 `.preview/server.log`。优先使用本机 Node.js，未安装时使用当前电脑已有的 Codex Node.js 运行时。

也可以使用 Node.js 18 或以上运行：

```sh
node scripts/server.mjs
```

默认地址 http://127.0.0.1:5173/ ，可通过 `--port 端口号` 指定端口。修改服务端路由或组件后，需要重启此命令；仅修改 CSS 和浏览器脚本时刷新页面即可。

## 页面结构

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 功能介绍 | `/features/` | 原首屏、两步设置、悬浮运行与专注统计演示 |
| 下载软件 | `/download/` | 原结尾下载内容、Windows 版本信息、下载说明及体验入口 |
| 高级会员 | `/membership/` | 完整的免费版 / 专业版定价、权益和方案选择 |
| 帮助中心 | `/help/` | 完整的 8 项常见问题与回答 |

根地址 `/` 显示功能介绍页。导航、品牌链接和下载入口使用普通页面链接；每页拥有独立 HTML、标题、描述和当前导航状态。原生浏览器历史支持前进、后退及新标签页打开。页面加载与历史恢复均回到顶部，页面内的功能提示和下载详情仍可使用锚点。

导航内容最大宽度为 1160px，在 1920px 页面中左右各留白 380px。功能、会员及帮助区块使用 `#001137` 纯色背景，首屏和下载页沿用原夜景图片。

## 检查与构建

```sh
node scripts/check.mjs
node scripts/test-floating.mjs
node scripts/test-routes.mjs
node scripts/build.mjs
```

构建结果在 `dist/`。四个路由分别输出各自的 `index.html`，可以部署在支持目录索引的静态服务器根目录，不需要 SPA 回退规则。不要直接用 `file://` 打开页面，ES Modules 需要 HTTP 服务。

结构检查覆盖内容归属、文案完整性、导航、锚点、ARIA、素材和页面文档；悬浮测试覆盖 8 种尺寸、滚动进度、连续过渡、向上还原、右上角定位和减少动态效果；HTTP 测试覆盖直接访问、路由别名、HEAD、静态资源和 404。

## 交互与接入

功能页保留倒计时、任务清单、统计周期及日期切换。悬浮运行区采用上方居中文案、下方全内容宽度桌面的结构。桌面演示在滚动阶段短暂停留，窗口随向下滚动连续缩小、淡出为桌面右上角的计时条；向上滚动沿相同轨迹恢复。折叠仅由滚动进度决定，没有自动播放、点击切换、拖动吸附或重播按钮。系统选择减少动态效果时，以静态状态切换代替位移。软件窗口底部操作栏及右上角装饰仅作静态展示，悬浮区允许正常触屏滚动。其他页面仅初始化其实际存在的组件，导航状态由当前路由决定。

所有交互均为前端演示，演示状态保存在当前文档内存中，刷新重置。下载页明确说明尚未接入安装包；会员方案选择不会创建订单或产生扣费。正式接入时更新下载页入口、`src/app.js` 的 `showUpgrade()`、价格权益和隐私政策。

## 文件结构

- `src/routes.js`：四个页面的路径、标题和描述。
- `src/components.js`：共享导航、页脚、弹窗及各页面内容。
- `src/app.js`：页面内交互、状态和滚动恢复。
- `src/floating-demo.js`：独立的悬浮窗演示。
- `src/data.js`：原有价格、权益及 FAQ 文案。
- `src/icons.js`：本地 SVG 图标与品牌。
- `styles.css`：视觉规范与响应式样式。
- `scripts/document.mjs`：生成每个路由的完整 HTML。
- `scripts/server.mjs` / `build.mjs`：本地预览与静态页面构建。
- `assets/`、`sc/` 及原始参考 PNG：软件截图、背景及原始素材。
