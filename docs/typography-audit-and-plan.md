# 官网字体审查与统一方案

日期：2026-10-31

范围：功能介绍页的 9 个主区块、下载页、高级会员页、帮助中心，以及共享导航、页脚和官网弹窗。

下方审查表记录统一前的基线。方案现已落实到 `styles/typography.css`，四个页面、404、共享导航、页脚及官网弹窗均接入；基础样式和页面专用样式的重复字体声明已清理。数值来自 CSS、加载顺序和媒体查询的代码检查，不是浏览器截图测量。软件截图和软件预览内部的文字单独处理。

## 结论

字体家族基本统一，字号、字重、行高、字距和部分文字颜色尚未形成完整的统一标准。需要统一的是同级文字的规则，同时保留页面标题、功能标题、正文、价格和计时数字的层级。

官网营销文字继承同一字体栈：`"Segoe UI", "Microsoft YaHei", "PingFang SC", system-ui, sans-serif`。没有必要为这次统一额外引入字体。不同系统实际使用的字体仍取决于系统字体可用性。

## 其他不一致

1. **副标题**：首页 18px，下载页最高 26px，会员页最高 24px，帮助页 18px；行高也有 1.6、1.65、1.75、1.8 等不同取值。
2. **功能卖点标题**：拦截区 16px，统计区和个性化区 17px，三种形态底部 19px，下载页 20px，目标区最高 24px。类似的图标加说明结构没有共用字体规格。
3. **功能卡片标题**：三种形态卡片 26px，生活价值卡片 22px，帮助分类 19px；需要按卡片标题和较小功能卖点区分，而不是分别手写。
4. **按钮**：通用按钮 15px，首页主按钮和导航体验按钮 16px，会员按钮 20px，下载按钮 24px，收尾按钮 20px。建议明确普通、大型两档。
5. **页脚**：帮助页单独覆盖字体。桌面品牌文字为 22px，其他页面为 19px；帮助页版权为 12px，其他页面为 10px。移动端版权分别为 11px 和 9px。
6. **弹窗**：官网弹窗标题 25px / 23px，说明文字 13px / 12px。可归入统一的弹窗标题、正文和辅助说明层级。
7. **颜色**：功能区主文字多为 `#0D2346`，下载及会员使用 `#0D1B30`，全局默认是 `#242B35`。次要文字也有 `#64758C`、`#718092`、`#7485A0`、`#738198` 等不同版本。
8. **维护方式**：同类文字分散在基础样式、区块样式、页面专用样式和多组媒体查询中；部分早期字号会被后续规则覆盖，需要查看最终优先级才能确定大小。

## 已实施的统一标准

以下为默认 16px 根字号下的像素参考，实施时使用 `rem`。桌面为宽度 ≥1200px，平板为 768–1199px，手机为 ≤767px。

| 文字角色 | 桌面 | 平板 | 手机 | 字重 | 行高 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 页面大标题 | 56px | 44px | 36px | 700 | 1.25 |
| 功能区块标题 | 44px | 36px | 30px | 700 | 1.30 |
| 会员方案标题 | 28px | 26px | 24px | 600 | 1.35 |
| 普通卡片标题 | 22px | 20px | 18px | 600 | 1.40 |
| 图标旁的功能卖点标题 | 20px | 18px | 18px | 600 | 1.40 |
| 页面副标题 | 20px | 18px | 16px | 400 | 1.60 |
| 正文和功能说明 | 16px | 16px | 15px | 400 | 1.75 |
| 辅助说明 | 14px | 14px | 13px | 400 | 1.60 |
| 小标签、版权和简短备注 | 12px | 12px | 12px | 500 / 400 | 1.50 |
| 导航文字 | 14px | 14px | 14px | 500，当前项 600 | 1.40 |
| 普通按钮 | 16px | 16px | 15px | 600 | 1.40 |
| 大型下载 / 升级按钮 | 18px | 18px | 16px | 600 | 1.40 |
| 官网弹窗标题 | 24px | 24px | 22px | 600 | 1.35 |
| 价格数字 | 64px | 56px | 52px | 700 | 1.00 |

具体应用：

- 功能介绍首屏、下载、会员、帮助中心主标题及收尾的大标题使用同一「页面大标题」规格。
- 三步设置、三种形态、个性化、拦截、目标与任务、统计、生活价值使用同一「功能区块标题」规格。
- 各区块底部、图标旁的功能卖点统一 20px / 18px，不再各自使用 16、17、19、24px。
- 会员方案名、价格数字和计时数字具有独立用途，保留专用规格。
- 所有页面共享页脚字体：品牌文字 20px / 18px，链接及品牌说明 14px / 13px，版权 12px；帮助页取消单独的字体覆盖。

字重归并为 400、500、600、700 四档；标题字距统一为 `-0.02em`，正文及按钮为 `0`。英文小标签可用 `0.08em`，中文小标签为 `0`。

文字色建议统一为：主文字 `#0D2346`，正文 / 副标题 `#64758C`，辅助文字 `#8492A6`，品牌强调 `#FF7D28`。橙色继续用于标题重点和短标签，长段正文使用灰蓝色。

标题与副标题间距建议统一为桌面 16px、手机 12px；卡片标题与说明统一为 8px。文字块到下一内容区沿用现有 `--section-gap`，不增加视口高度占位。

## 实施方式

1. 新建统一字体变量，例如 `--font-sans`、`--type-page-title`、`--type-section-title`、`--type-body`、`--type-caption` 和字重 / 行高变量。
2. 让同一文字角色使用公共排版类或同一组变量。现有主标题和模块标题仍保留各自的 HTML 标题层级。
3. 逐个替换四个页面和功能区块的局部字体声明，清理已经失效的字号及重复媒体查询。只追加一个全局覆盖规则不足以解决来源分散的问题。
4. 统一共享页脚和弹窗的文字规格。导航保留现有组件和功能。
5. 保留现有布局结构、文案、配色氛围、图片比例与业务交互；字号调整后核对自然换行和按钮宽度，不用裁切或缩放整块文字处理溢出。

## 不应跟随统一的内容

- PNG / WebP 软件截图中的文字属于图片像素，不通过官网 CSS 修改。
- 个性化预览、下载预览中的软件 UI、倒计时和 `cqw` 字号保持其组件比例，不套用营销文案的主标题规格。
- 价格和计时数字可以大于正文，但使用明确的专用样式。

## 实施后的验收

- 对比 1366×768、1920×1080，以及常见手机宽度；同类标题、正文、按钮和页脚应一致。
- 核对 100%、75%、50%、25% 缩放时的换行、溢出和版块衔接，仍由内容决定高度。
- 检查导航、下载 / 会员入口、FAQ、角色与主题切换、各轮播和弹窗。
- 进行实际浏览器视觉核验，确认字体回退、字重、换行及图片与文字的比例；代码数值检查不能代替这一步。

## 代码与验证

- `styles/typography.css` 集中定义字体、三档字号、字重、行高、字距、文字颜色及对应角色的选择器；在所有页面最后加载。
- `styles.css`、`styles/download.css`、`styles/membership.css`、`styles/help.css` 保留布局及交互状态样式，取消重复字体声明。帮助页不再单独覆盖页脚字体。
- `styles/product.css`、应用交互代码、页面 HTML、素材、文案及业务数据在本次字体统一中保持原样。软件 UI 的 `cqw` 字号、截图文字与演示时钟独立管理。
- `scripts/test-typography.mjs` 检查实际页面节点对应的 CSS 优先级、320 / 390 / 767 / 768 / 1024 / 1199 / 1200 / 1366 / 1920px 断点、放大根字号、25% / 50% / 75% / 100% 的数值缩放及预览样式隔离。该检查不模拟浏览器字形测量或视觉渲染。
- 已通过项目完整回归测试与静态构建；本地四条路由均返回 200 并加载最新共享字体样式。与修改前快照对比，页面 HTML、现有布局属性、共享区块间距、软件 UI 样式及应用交互代码一致；新增文字间距规则只作用于标题 / 说明的对应角色。
- 当前环境的浏览器访问此前被安全限制拒绝；本轮不绕过该限制。实际字体回退、换行及视觉比例仍需在浏览器中人工确认。
