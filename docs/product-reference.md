## 核心卖点与流程

减少网站和应用打断；让窗口占用更少桌面空间；把专注投入关联到目标和任务；通过总览、日历及目标记录回顾长期投入。

流程：下载 Windows 软件 → 设置访问控制清单 → 选择目标（可选）与时长 → 开始专注 → 使用悬浮或折叠窗口 → 记录任务 → 在统计页面回顾。
